# Тест-план

## Цель и основание
Проверить каталог, поиск, навигацию и избранное VK Marusya версии `2662d00144b4511ccf323cac46736642584df37b`. Ожидания выведены из текущего кода и пользовательских сценариев, отдельной утверждённой спецификации нет. Изменение продуктовых требований требует пересмотра ожиданий.

## Включено
Локальный каталог (8 фильмов), поиск по подстроке без учёта регистра, очистка поиска, пересечение поиска и фильтра избранного, счётчик, сохранение/удаление избранного, карточки, HashRouter, ошибочные ID, удалённая карточка с замоканным TVmaze, адаптивность и базовые проверки доступности.

## Исключено
Потоковое видео, оплата, авторизация, нагрузочное тестирование, проверка всех данных TVmaze, полноценный аудит безопасности и сертификация WCAG. Автоматические тесты не отправляют заявки и не используют персональные данные.

## Среда и данные
Node.js 20+, Chromium через Playwright 1.62.1; основная ширина 1280, мобильная 390. Ручная матрица: Chromium/Firefox/WebKit, 320/390/768/1280px, масштаб 200%. Эта матрица запланирована, не подтверждена выполнением. Каждый тест получает новый browser context. Локальные фильмы «Брат», «Брат 2», «Холоп»; удалённый ID 1 с fixture; отсутствующий запрос `несуществующий-фильм-987`.

## Риски и приоритеты
P1: потеря избранного, ошибки поиска, недоступный запуск. P2: ошибочные маршруты, восстановление после сетевой ошибки, горизонтальная прокрутка. Дополнительные риски: некорректный JSON localStorage, доступность повторяющихся heart-кнопок, гонка запросов удалённых карточек и различие версии GitHub Pages с исходниками. Это гипотезы до воспроизведения.

## Порядок
1. Проверка установки и версии приложения.
2. Smoke: каталог, карточка, поиск, избранное.
3. Негативные проверки, API fixtures, адаптивность/клавиатура.
4. Фиксация результатов и воспроизводимых дефектов; повторная проверка исправлений.

## Критерии
Вход: приложение стартует; зафиксированы commit и окружение; нет реальных аккаунтов/секретов. Выход: P1-кейсы выполнены, результаты и ограничения записаны, критические дефекты исправлены или явно приняты владельцем. Сейчас критерий входа для локального UI не выполнен из-за BUG-001.

## Отчётность
Статусы: NOT RUN, PASS, FAIL, BLOCKED. Наличие тестового файла не означает PASS. Для дефекта нужны шаги, actual/expected, окружение и доказательство. Непроверенные предположения остаются рисками.
