# Чек-листы (подготовлены, не отмечены пройденными)

## Функциональность
- [ ] Каталог показывает 8 уникальных локальных фильмов.
- [ ] Поиск по подстроке, кириллице, регистру и пробелам.
- [ ] Очистка поиска, нулевые результаты, быстрый ввод.
- [ ] Добавление/удаление избранного из каталога и карточки.
- [ ] Счётчик и localStorage совпадают после reload.
- [ ] Поиск учитывает активный фильтр избранного.
- [ ] Ссылки, history back/forward и прямой hash URL работают.
- [ ] Невалидный ID/маршрут позволяют вернуться домой.
- [ ] Удалённая карточка: HTTP 503, offline, пустые image/rating/summary.
- [ ] Повреждённый movie-favorites не приводит к необработанному падению (проверка риска).

## Адаптивность
- [ ] Каталог и детали на 320/390/768/1280px без горизонтальной прокрутки.
- [ ] Длинные названия, поле поиска и кнопки не обрезаются.
- [ ] Масштаб 200%, портретная и альбомная ориентация.
- [ ] Нет перекрытия sticky header и контента.
- [ ] Тач-кнопки удобно нажимать; переключение ориентации сохраняет состояние.

## Доступность
- [ ] Полный сценарий поиска/избранного/возврата выполняется клавиатурой.
- [ ] Видимый фокус; логичный порядок Tab без ловушек.
- [ ] Названия ссылок и кнопок понятны screen reader; heart-кнопки различимы по фильму.
- [ ] Состояние избранного объявляется, а не только меняет символ/цвет.
- [ ] Заголовки и landmarks образуют понятную структуру.
- [ ] Динамический результат поиска и ошибки объявляются.
- [ ] Контраст текста и контролов проверен инструментом, не на глаз.
- [ ] Картинки имеют подходящие альтернативы, декоративные элементы не мешают.

Чек-лист не означает соответствия WCAG. Неотмеченные пункты требуют фактической проверки.
